## Question
For each SAE concept, compare its share of the concept distribution in Olmo 3's pretraining data (Dolma 3 stage 1) with its share in text the model writes unprompted. Prediction (Angela, 2026-10-21): concepts underrepresented in Dolma become rarer in rollouts, and overrepresented ones become more common.

Maps to Sheng-Yu's RQ3 (gap between training data and model output, separated from SAE train/test error). Exp 1 deferred it (Exp 1 design.md F1; `notes/limitations_exp1.md` item 22).

Precedents:
- Bohacek et al. 2025, "Uncovering Conceptual Blindspots in Generative Image Models Using Sparse Autoencoders" (arXiv:2506.19708), does this for images. It compares each SAE concept's activation on training images with its activation on generated images (δ(k), Eq. 1), and Fig. 13 plots training frequency against the gap.
- Shumailov et al. 2024 (Nature 631:755) report that distribution tails vanish when models train on their own output. Their setting is repeated retraining; we measure one round of generation.

## What each data set is used for
| Data | Used for | Never used for |
|---|---|---|
| Dolma train (Exp 1, 39,949 docs) | x order: concept rank by χ_train (Eq. 1-2, all sources) | Testing; it sets the order, so testing on it would show regression to the mean |
| Dolma V (Exp 1, 9,955 docs) | Null: how far a fresh Dolma sample of rollout size moves from χ_train by noise alone | Setting the order or any pilot threshold |
| Rollouts, stage-1 checkpoint (10,000) | Main test | Setting the order |
| Rollouts, final model (10,000) | Second test: adds the effect of stage 2/3 data | Setting the order |
| Pilot rollouts (200 per generator) | Throughput, batch size, degeneration threshold, reading by eye | The reported result; they are generated with a different seed and not reused |
| Rollouts, Olmo-3-7B-Instruct-SFT, -DPO, -Instruct (10,000 each, run `full_post`, G30-G36) | Third test: the effect of post-training, against the same V and Dolma order | Setting the order |
| Pilot rollouts of the three post-trained generators (200 each, run `pilot_post`) | Stop ids, special-id counts, lengths, reading by eye, projected G16 counts | The reported result (pilot seeds, G6) |

The SAE was trained on the Pile (CLAUDE.md), so Dolma train, V and the rollouts are all outside SAE training. The model saw every Dolma doc (Exp 1 row 3); it saw none of the rollouts as input.
