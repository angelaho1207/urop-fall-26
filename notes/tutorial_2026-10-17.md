## Chunk 3 — Tunnel job + Claude Code on the node

The tunnel must run inside a Slurm job (compute node, GPU), never in your login shell. `tools/tunnel.sbatch` sets the job's folder with `--chdir`, so it starts in `~/urop-fall-26` no matter where you run `sbatch`.

**On ORCD (terminal 1):**
1. `ssh angela_h@orcd-login.mit.edu`
2. `cd ~/urop-fall-26 && git status` — check for uncommitted changes before pulling.
3. `git pull` — brings in `CLAUDE.md`, `exp1_concept_coverage/design.md`, `tools/tunnel.sbatch`.
4. `cat tools/tunnel.sbatch` — read it (line-by-line explanation in chat).
5. `sinfo -p mit_normal_gpu -o "%P %l"` — shows the partition's max time. If it is not `6:00:00`, change the `-t` line to match (`nano tools/tunnel.sbatch`).
6. `mkdir -p logs` — Slurm cannot write the log if the folder is missing.
7. `sbatch tools/tunnel.sbatch` — prints `Submitted batch job <JOBID>`.
8. `squeue --me` — repeat until the `tunnel` job shows `R` (running). `PD` means waiting for a GPU.
9. `cat logs/tunnel_<JOBID>.out` — check:
   - first line `host:` is a compute node name, not `orcd-login...`
   - the `Open:` URL ends in `/home/angela_h/urop-fall-26`
   - if it shows a GitHub device code, open https://github.com/login/device on the laptop and enter it

**On the laptop (VS Code):**
10. Ctrl+Shift+X → search **Remote - Tunnels** (publisher Microsoft) → Install (skip if installed).
11. Ctrl+Shift+P → **Remote-Tunnels: Connect to Tunnel...** → **GitHub** → sign in with the same GitHub account → pick **orcd-cg**.
12. File → Open Folder → `/home/angela_h/urop-fall-26` → OK.

**In the tunnel window: Terminal → New Terminal:**
13. `hostname` — compute node name.
14. `nvidia-smi` — one GPU listed.
15. `source ~/venvs/cg/bin/activate && which python` — path ends in `venvs/cg/bin/python`. Run the `source` line in every new terminal.
16. `python -c "import torch; print(torch.__version__, torch.cuda.is_available())"` — must print `True`.
17. `df -h ~` — note free space (model ~15 GB + SAE 2.1 GB).
18. `pip freeze > requirements.lock` — records exact package versions.
19. `claude` — press `c` to copy the login URL, sign in on the laptop, paste the code back. Then `/model` → Opus 5.5.
20. In a second terminal: `sbatch --test-only -p mit_normal --wrap=hostname` — confirms jobs can be submitted from the node.

Done when: steps 13-20 all pass. When finished for the night: `scancel <JOBID>`.

Troubleshooting:
- Job stuck in `PD` with reason `PartitionTimeLimit`: `-t` exceeds the partition max (step 5).
- Log says a tunnel lock exists: delete `~/.vscode/cli/tunnel-stable.lock` and resubmit (HMS O2 guide).
- `torch.cuda.is_available()` is `False`: stop and tell Claude; torch must be reinstalled for the cluster's driver.
