One dot per concept that fires often enough in both web samples to compare. The y axis is the log ratio of the concept's coverage in Dolma web to Pile web (CG paper Eq. 2); the dashed lines are the 10th and 90th percentiles that define under and over. Ringed dots are the 240 sampled concepts; click one to open its page.

Concepts per class

Each concept's log ratio measured on two disjoint halves of both samples. Points far from the diagonal are concepts whose ratio depends on which documents were drawn; class labels near the cut lines can flip between halves.

What kind of token each concept fires on most strongly, taken at its peak in every document where it fires, in Dolma web and Pile web text (weighted equally). Bars: share of concepts in each class whose most common peak token is of that type, with 95% bootstrap intervals. All 46,360 compared concepts are included, not only the named sample.

Topic categories of the 240 named concepts

Categories proposed by Claude Opus 5.5 from the 240 concepts' names without seeing their class; each concept was then placed in one category by Opus and, separately, by Sonnet 5.5. Bars use the Opus coding with 95% bootstrap intervals; with 80 concepts per class, only differences of about 10 points or more can be read.

80 concepts drawn at random from each of over, under and middle (row F3). Each has a name written from Pile web examples and one from Dolma web examples; the quiz columns give how well each name predicts where the concept fires in held-out Dolma web text (balanced accuracy, 0.5 = chance).
