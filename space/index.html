Details and checks

Methods and definitions: rollout sampling (temperature 1, no top-k or top-p), χ, r, classes (over, under, middle), Δ slope, name quiz

Rollouts. Each model writes unprompted from <|endoftext|> at temperature 1, with no top-k or top-p, although post-trained configs recommend 0.6 and 0.95. A post-trained rollout ends at the model's first <|im_end|> or <|endoftext|>. Special-token ids are removed before encoding, since Dolma's SAE inputs contain none.

χ and r. χ is a concept's coverage relative to the average concept (CG paper Eq. 2). r = ln χset − ln χtrain. All sets in a comparison use the same number of documents, since fewer documents alone steepen the curve. Slope statistics are over the slope concepts (G13).

Classes and lists. Per model, concepts with χtrain ≥ e−5 are ranked by r: lowest 10% = under, highest 10% = over, the rest = middle (CG paper Sec. 3.1, 5.1). Random lists: 80 per class. Extreme lists: the 50 highest and 50 lowest r, unfiltered and among concepts with at least 50 firing docs on both sides.

Name quiz. 200 list entries, 100 per group (base = stage1, main; instruct = SFT, DPO, Instruct). Each gets a name from Dolma windows and one from that model's rollout windows, and both are quizzed on the same held-out Dolma V windows (30 firing + 30 non-firing, balanced accuracy, Paulo et al. detection). Design: exp2_rollout_gap/design.md G70-G74. Window text stays off this page (G20).

Shuffle vs shape table: rank-shuffle share, shape share, Spearman ρ, Var(r), trend share, excess dispersion sd

Dpair = mean r² (concepts paired by id). Dmarg = the same after sorting each side, so it sees only the two histograms. Shape share = Dmarg / Dpair; rank-shuffle share = the rest. Var(r) splits into a trend part, (b − 1)² Var(ln χtrain) from the line fit of ln χset on ln χtrain, and the scatter around that line; the trend share is the part a slope can describe. Excess dispersion sd = √(Var(r) − the set's noise − train's noise), noise from split halves, in ln units; V defines train's noise (G40, G42).

Δ slope robustness: all docs, length-matched, garbled removed, count control

Bold: bias-corrected Δ (G45). Below it: raw Δ and its 95% basic bootstrap interval (G17). Each column applies one document choice to every set, V included. Length-matched: in each length bin, every set cut to the smallest count (G43). Garbled removed: docs whose mean token NLL under the encoder model is above V's 99th percentile dropped (G58). Count control: random drops to the garbled-removed count, 20 draws (G60). Count control minus all docs is what the smaller count does alone; garbled removed minus count control is what the flag does.

Top χ-mass gainers, losers and controls: 41 moved and 20 control concepts, names from Dolma vs rollouts, quizzed on both sides

Per set, the 10 concepts that gained and the 10 that lost the most χ mass (41 distinct, each tested with the set where it moved most), plus 20 controls matched in frequency. Each was named twice by Claude Opus 5.5, from 40 Dolma V windows and from 40 rollout windows, and each name was scored by Claude Sonnet 5.5 on held-out windows from both sides. Gap on Dolma = Dolma name's score − rollout name's score, on Dolma windows; gap on rollouts = the reverse, on rollout windows. Agree = both gaps ≤ 0.13, the 95th percentile of the same gap between two human corpora in Exp 1. Not scored = fewer than 90 of 100 windows answered on a side (G47-G53).
